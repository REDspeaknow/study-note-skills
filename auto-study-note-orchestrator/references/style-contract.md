# 复习笔记版式契约 v3

复制 assets/通用笔记模板.tex 与 assets/study-note-style.sty，使用 XeLaTeX。内容遵循[正文写作规则](../../study-note-unit-writer/references/unit-writing.md)。

## 阅读结构

章节直接列出星标知识点；标题与目录隐藏数字编号，最多章节与必要主题两层。\StudyPoint 用于模型、题型等块状入口；\StudyTerm 将星标、蓝色粗体名称、冒号与定义连续排在同一段，接近数字经济参考稿的紧凑正文。

标题区仅放课程、范围和一次星级图例；目录按需添加，默认只列章节。来源与流程留后台。公式速查按需在所有正文后添加一次。

## 参考稿的蓝边框

数字经济原 TeX 的相关框使用 \fcolorbox{termcolor!40}{boxbg}、0.92\textwidth 的 minipage 和 \small。蓝色指边线，原背景为暖白色 RGB(252,250,242)，并非蓝色填充。原稿的框也用于一些逻辑串联；本模板仅借其视觉，不因此生成串联文字。原稿例题并非全部入框，本版依据用户要求把推导和例题整体入框。

v3 的 proofbox、examplebox 与可选 formulabox 统一采用：细蓝边 termcolor!40、暖白底、方角、居中、内容区宽度约 92%、框内 \small，粗体题头在内容区内，没有独立彩色标题栏。tcolorbox 代替不能自然跨页的 fcolorbox/minipage；跨页属于技术适配，并非与原稿完全相同的实现。

框的单位是一整个推导或一道完整例题。普通展示公式允许无框；不能把设定、每个等号和结果分拆入框。旧的其他框保留定义用于编译兼容，新稿不使用。

## 技术与验收

沿用 FandolKai 正文、FandolSong Bold 粗体、Times New Roman 西文和 XITS Math 数学字体；A4、四边 2cm、1.15 行距、无框链接。框内小号字是本次向参考稿校准的修改，其余字体配置不变。

标签用 \label{kp:...}，隐藏编号后用命名 \hyperref[kp:...]{知识点名称} 检索。渲染核对概念入口、完整推导、例题和跨页框；看边线、底色、题头与文字密度，不能只看是否有蓝色。自动报告仅检查所列结构和技术项，不认证定义准确性、重点、精练程度、推理充分性或课程覆盖。
