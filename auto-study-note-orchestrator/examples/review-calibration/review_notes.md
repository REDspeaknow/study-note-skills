# 样例来源与范围

本样例依据用户提供的平台经济现有正文及 build/transcripts 转录整理；当前对比文件夹没有原始课件 PDF。只核对下列选段，不声明原课件覆盖。星级均按知识结构暂定，正式使用须以教师和考试证据调整。

编译前将 ../../assets/study-note-style.sty 复制到本目录，再以 XeLaTeX 编译复习密度校准.tex。这样只维护一份样式源文件。

| 选段 | 来源 | 处理 |
| --- | --- | --- |
| 平台与网络效应 | u01_body；lec1_p06-25 转录；规模经济定义见 u03_body | 直接定义，四类安排只写一次，删品牌列举、表格复述及段末串联 |
| 价格结构与线性需求算例 | u02_body | 合并公式链；保留独立性、链式负号和非负约束；修正“局部一阶变化为零=价格结构中性”的错误推断 |
| 新旧网络需求、收费及算例 | u17_body | 合并同一模型的设定与运算；保留效用式、无差异条件、需求、利润导数、内点条件和原数值例题 |

样例没有重写选段以外的全部知识。u17 的比较静态、一般角点解等未纳入这个局部示范，正式全书仍须按范围核对。局部平稳但非全局中性的对称线性需求反例是用于澄清数学区别的补充，不冒称课件原例。

框的视觉参数依据数字经济参考 TeX 中的 fcolorbox：termcolor!40 边线、boxbg 暖白底、small、约 92% 文本宽度；保留现用正文与数学字体，使用可跨页实现。数字经济原稿的长衔接框和个别数学错误不作为写作范本。
