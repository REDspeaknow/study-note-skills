# 审核方法

先展开 TeX 的 input/include，读取 build 中的实际正文。对照用户范围、可用来源和参考稿；只有旧笔记或转录时，不认证原课件覆盖。

## 内容审核先于脚本

1. **知识点与定义：**名称是否准确、边界是否清楚、定义是否紧接入口且完整；对照课程原定义确认关键特征和条件未被压缩掉。句数短不构成优点，必要解释较长也不构成冗余；低星概念同样须准确完整。模型参数和运算步骤是否被误升为独立点。每个独立概念、定理、结果和题型应有星级；封面图例和星号总数不能代替检查。
2. **重要性：**教师/考试证据优先，推断星级标为暂定。读者能否辨认核心与背景；是否把导读、分析顺序、模型分工和批次总结加星混入知识内容。无须按配额分星。
3. **重复与归组：**结合相邻内容和跨章节复用，检查同一内容是否只完整讲一次；定义、表格、图注、逻辑链、推导和例题前后是否重复讲解同一含义，后续使用是否简短引用且标签有效。首次讲解、新条件、独立证明/结果及本题关键计算不能被引用取代；按需设置的全书公式速查可摘录结果与条件。同一模型的设定、条件、推导和对应例题应集中在同一星标入口；指出不必要的小标题、重复入口与连续碎框，保留独立定义和不同星级。删除铺垫和转场；定义可直接并列，不强制改成“结论先行”的答题清单。
4. **必要解释：**删除衔接后，概念的关键特征、机制、条件和推理是否仍完整；文字减少不能抵消定义含糊或步骤跳跃。
5. **数学：**从设定复算关键链条，检查新符号、条件概率、积分区间、链式法则、约束和边界。尤其核对必要/充分、局部/全局、候选/实现。不能把某点导数为零写成函数不随变量变化。
6. **题目：**逐小问核对题面条件、代入、中间结果和答案；确认决定答案的可行性、最优性或边界判断已实际做出。不能用“检查边界”取代计算。
7. **覆盖：**每个实质来源项有实际正文位置或合理省略，删掉的是重复表达而非独立知识。第二证明若有独立含义或考试要求，不能机械去重。
8. **机制图表：**对照课件用于解释机制、过程、交点、均衡、曲线移动和比较关系的图与表格，检查其直观解释作用是否在正文中清晰保留。文字/公式已讲同一知识、页数偏多或文字未超过100字，均不构成省略原图表的理由；不同条件和分步变化不能按主题相同去重。核对坐标轴、曲线、交点/阈值、条件、关键比较维度及可读性，检查是否虚构定量关系。省略应有信息与解释作用均已被保留图表充分覆盖或纯装饰的依据；不能只按图表数量认定覆盖，也不能用全局思维导图替代具体机制图表。
9. **表达类型：**数理推导应显示数学链。文字逻辑链不强制配置，仅在连续文字推理段明显超过 100 字时按需采用；短段保留简短文字或条目即可，不能因未画图判为不合格，也不设自动字数门槛。完整定义和必要题面不受此转换条件约束。采用逻辑图时，核对浅绿底、紧凑节点与间距、必要关键词加粗，以及前提、关键环节和条件是否完整。箭头不能把并列写成因果、把可能写成必然、把必要条件写成充分条件；不要把长段搬进节点或条目，也不靠缩小字号删条件省篇幅。步骤框若重复推导或例题，应合并。

## 框与 PDF

一个推导/例题是否完整集中在一个框；是否残留设定框—推导框—结果框的连续碎片。普通辅助公式允许无框，不能仅按展示数学是否入框审核。

按 style-contract.md 核对细蓝边、暖白底、小号文字、框内题头、无独立标题栏；原稿的逻辑串联框不能作为生成串联段的理由。查看概念、数学、例题和跨页框的实际渲染，检查文字可读、字体嵌入、链接与引用稳定。

整本笔记核对标题区后是否有一张与实际内容一致的全局思维导图，位于可选目录及正文之前；检查层次、主要分支、短标签和连线，避免长说明。正文知识图不当作重复全局导图。

先逐点完成以上内容审核，再读当前输出的编译与校验报告。自动通过仅表示所列结构/技术项通过。页数、字数、星标数和框数只能提示问题，不能作为内容质量的通过标准。

## 输出

仅列具体位置、问题、来源依据和修正建议，给出“通过 / 有说明地通过 / 需修改”。明确区分内容审核与技术结果，附真实未验证项。自审如实称自审。公式速查按需在全部正文后集中一次。
