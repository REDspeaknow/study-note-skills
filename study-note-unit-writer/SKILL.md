# 星标知识点写作

先读取 [references/unit-writing.md](references/unit-writing.md) 与其中链接的实际段落校准，按知识点边界、定义、星级和推导规则写作。使用 study-note-style-v3；一个完整推导或例题一个蓝边框，辅助公式不单独建框。

完成分配范围中的知识点；沿用既有记号和标签，核对定义准确性。各知识点直接展开，删去导读、铺垫、转场与重复总结；保留必要解释和计算。分批只是执行范围，不自动产生标题。独立知识点必须标星，普通参数和中间步骤归入所属模型。

## 交付

- 指定的正文 .tex 片段：包含星标知识点、必要的解释和蓝框；不含导言区、全书目录、全局复盘或公式速查章节。
- 有疑点时简短返回来源位置、问题及受影响知识点；没有疑点直接返回正文路径。默认不生成交接 JSON。

只有接续已有工程且主编明确要求原交接格式时，按该工程的既有格式返回覆盖与候选公式。追踪数据留在正文之外；主编维护统一记录。不要为了填满流程字段扩写知识内容。
