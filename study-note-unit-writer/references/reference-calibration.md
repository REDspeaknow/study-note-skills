# 正文样例说明

必读的 [body-example.tex](body-example.tex) 是正文片段，示范按内容选择完整定义、数学链、文字逻辑链、必要图表与例题，包含以下表达类型：

| 位置 | 观察重点 |
| --- | --- |
| 平台与网络效应 | 星标、名称、定义同段；分类和必要解释紧邻定义，不补串联段 |
| 场景分化与多个稳定大网络 | 原截图的连续推理段明显超过100字，按需改成带前提的紧凑浅绿逻辑链，关键词加粗；案例简表和必要辨析分别保留，短段无需仿照画图 |
| 双边收费 | 数学公式链与完整计算例题；保留链式负号、约束和边界判断，不另重复步骤框 |
| 满足预期均衡 | 多句完整定义，保留一致性条件与唯一性、稳定性的区别 |
| 新旧网络竞争 | 参数以简表呈现，保留必要分界图；无差异条件、需求、利润与适用条件写成数学链 |

样例星级按知识结构暂定。实际课程以用户、教师和考试证据为准；样例长度不是定义或章节的上限。课程原定义、条件和所问小问应完整保留，精简靠删去铺垫与重复实现。

样例依据平台经济现有笔记及转录编写，具体来源和局部范围见 [review_notes.md](../examples/review-calibration/review_notes.md)。可打印版本的入口为 [复习密度校准.tex](../examples/review-calibration/复习密度校准.tex)，其通过 input 引用本正文，避免维护两份内容。主编编译时将总编排器 assets 下的 study-note-style.sty 复制到入口同目录。

计量经济学需要观察较长的代数链与跨点复用时，再读 [OLS 正文样例](../examples/ols-and-r-squared/ols-body.tex)。该例保留完整求导、消元、平方和分解及条件；其 merged.tex 展示全书速查放在所有正文之后。没有交接 JSON 或旧流程文件。

写作要求以 [unit-writing.md](unit-writing.md) 为准。示例用于帮助落实表达，不能代替课程来源或数学核对。
